Deployment

Rupert is currently hosted at rupert.stoverparc.org. The current production host is SER8 in an Incus instance.

Release and deployment

GitHub Actions runs CI and creates a GitHub release from a version tag. There is no automated production deploy configured in this repository. A release does not update the live instance.

The checked-in systemd units describe a previous host layout and are not the live Incus deployment runbook. Confirm the host's release procedure and backup status before promoting a release.

Database

Production uses PostgreSQL. The optional SQLite adapter is experimental and intended for local evaluation; it is not enabled for the live instance.

Backups

Rupert includes PostgreSQL backup and Google Drive backup support. The current production backup schedule, off-host copies, and restore procedure still need verification against the live Incus instance; the systemd backup files here are from the older host layout.

Continuous integration

CI runs in the official ruby:4.0 container against PostgreSQL: RuboCop, migrations, Tailwind build, asset precompile, and the full test suite. Every push or pull request triggers it.
