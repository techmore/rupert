Your shop's operations, in one place.

Rupert is a modular ERP for small commerce businesses. It syncs Shopify and Square into a single database and gives the back office one dashboard for sales, inventory, reconciliation, the ledger, orders, invoices, and shipping — plus a searchable customer CRM.

Rails 8.1 Shopify + Square sync Modular monolith Tailwind UI
Shopify→ Square POS→ Sync engine (Solid Queue)→ PostgreSQL→ Rupert dashboard

What's inside

The app is organized into four areas, each a set of modules that register themselves in a central registry.

OverviewCustomizable dashboard with sales, stock, and attention widgets.
CommerceSales journal, customers, inventory, and POS registers.
OperationsReports, reconcile, ledger, projects, goals, and KPIs.
TeamEmployee directory and a role × permission matrix.
SystemSync health, alerts, settings, backups, and the Buzz agent.

Recent additions

  • Order detail + printing — open any order to view a full invoice or packing slip and print either.
  • Fulfillment tracking — sync shipping addresses and tracking numbers, and mark orders in transition / shipped / arrived / completed.
  • Employees & permissions — a team directory with role-based access and per-person overrides.
  • Warehouse sales — secret vendor links with tiered pricing and a public storefront.

Quick start

# Ruby 4.0.6 + PostgreSQL 16 required
bundle install            # from web/
cp .env.example .env      # fill in credentials at repo root
bin/rails db:create db:migrate
bin/rails tailwindcss:build
bin/rails server          # http://localhost:3000
