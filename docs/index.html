Built for the back office

Print it, ship it, count it

The jobs your team actually does, day to day — done faster.

  • Print an invoice or packing slip for any order with one click.
  • Record carrier tracking and mark orders in transition, shipped, arrived, or completed.
  • Reconcile Shopify vs Square at the SKU level and apply a clean adjustment plan.
  • Run manual inventory counts with submit / approve / reject.
  • Keep roles tight — cashier, manager, admin, reader — with per-person exceptions.
# sync everything
bin/rails ops:sync

# print an order
open /orders/#1001

# mark it shipped
ship! #1001 → UPS 1Z999…

# stay on top of stock
alerts → resolve or ignore
