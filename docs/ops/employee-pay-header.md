# Employee pay header

The employee shell shows the signed-in worker’s latest reviewed earnings period in USD. Gross effective hourly rate is `(base pay + tips + store commission + eligible online commission + other bonuses) / hours worked`. Each component and the reporting dates remain visible. Zero hours, negative components, cross-workspace employees and overlapping periods are rejected. Missing reviewed periods display pending review; timesheet estimates are not relabeled as actual pay.

Payroll writers open **Payroll → Review employee earnings** to publish a complete 1–31 day period or correct one of the recent periods. Monetary inputs currently use whole cents. This is a reviewed summary, not a payroll posting, payment instruction, Zelle tracking or QuickBooks write. The attached associate report informed the breakdown; its Wednesday scheduling notes do not install a scheduled report. Commission eligibility and totals must be verified by the reviewer before publication. No automated commission reconciliation is claimed.

The migration adds one table and does not change existing pay records. Both schema adapters include it. Before deploying, verify the current release and database identity, acquire the existing deployment lock, preserve unrelated source changes, back up and rehearse the migration, and follow the current SER8 restart procedure. Do not run tests against the production database.

For a deliberately fake employee, run `bundle exec rails 'employee_pay:demo[email,workspace-subdomain]'` in the verified production environment. This explicit operator task creates only a demo employee/account and exact-email Google login approval. It refuses to replace a real employee, cross-workspace account or existing alias. It does not change an existing account’s role or password. `source=demo_pay` selects read-only synthetic earnings ($848 / 32 hours = $26.50/hour); no pay rate, shift, timesheet or payslip is seeded. Never auto-provision demos during migrations or sign-in. Google sign-in still requires the instance’s working OAuth configuration.
