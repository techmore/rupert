# Post-tuning independent answer review — 2026-10-28

Twelve checked questions were selected before these runs using seed 20261029: four each from the existing core, finance, and cross-tool repository batteries, excluding the preceding random sample. LFM3, Qwen and DeepSeek used the same synthetic fixture and runtime `4731a14c`. The questions and fixture existed before this review and may have appeared in earlier work. All 12 frozen references were usable; no case was dropped.

I scored the answers against the frozen references without using a model-generated grade. The model labels were randomized separately for each question and withheld until decisions were saved. I had seen previous related answers and run progress, so this is masked review rather than a fully blind study. Rubric: correctness 0–2; coverage, grounding and relevance 0–1 each. LFM scored higher than Qwen on this sample and tied DeepSeek under this rubric. All three omitted the requested timesheet-approval and bank-line status, and all failed to provide an overall refund amount. LFM and DeepSeek handled the tea task and stock uncertainty more completely than Qwen; LFM gave a clearer sync-coverage answer and performed the business-health lookup that Qwen skipped. The relevance point penalizes substantial unrelated output; different defensible scoring can change the ordering.

This is one run per model on a small, stratified sample of existing questions and a reused synthetic fixture. The references are generated by Rupert’s tools, not independent ground truth. These results do not prove that LFM generally beats Qwen or establish real-data accuracy. The targeted local real-snapshot replays are documented separately. Full synthetic answers, references, model runs and masked decisions remain in the local evidence directory.
