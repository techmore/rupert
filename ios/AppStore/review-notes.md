# App Review information

App Store Connect → version 1.0.0 → App Review Information.

**Sign-in required:** yes.

| Field | Value |
|---|---|
| User name | `appreview@rupertpos.com` |
| Password | (the owner sets it; see owner steps) |
| Contact | the owner's name, phone and email |

**Notes** (paste as is):

```
Rupert is back-office software for independent retail shops (sales, inventory, staff, bookkeeping). Accounts are created by a business, so we made a demo shop for you: "Juniper & Pine Market", filled with sample data. No real customer data is in it.

To sign in: on the first screen, tap "Sign in with email and password", then use the user name and password above. (Google sign-in is for business Google accounts.)

Native features to try:
1. Barcode scanning with the camera (VisionKit): Home → menu → Inventory → Counts → open the draft count → Scan → "Scan with camera". Point it at any product barcode; the code is saved to the count.
2. Face ID lock: tap the person icon at the top right of the Home tab → App settings → "Require Face ID". Leave and return to the app; it asks for Face ID and hides its pages in the app switcher.
3. Home Screen quick actions: touch and hold the Rupert icon → Team Chat, Ask Rupert, Notifications or Search.
4. Native tab bar with a separate navigation stack per tab, native sheets for forms, pull to refresh, and Google sign-in in the system authentication sheet (ASWebAuthenticationSession).

Account deletion: person icon on the Home tab → "Delete account", or the account menu (initials, top right of a page) → "Delete my account". Please do not delete the review account, or the next reviewer cannot sign in.

Subscriptions: the app sells nothing. Businesses subscribe on our website; the app does not show prices, plans or purchase links (guideline 3.1.3(c), enterprise services sold to organizations). Account sign-up is not offered in the app; it signs in accounts a business already has, so Sign in with Apple is not required (4.8).
```
