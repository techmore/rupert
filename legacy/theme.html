Opacity modifiers work too, e.g. bg-bubblegum/20, border-emerald/30. Tokens are defined in app/app.css via Tailwind v4 @theme.

Framework & tooling

Tailwind CSS v4

Utility-first styling via the @tailwindcss/vite plugin. Theme tokens live in app/app.css under @theme.

React Router v7

File-based routing in app/routes/. Loaders and actions handle server-side data on the React Router runtime.

React 18 + Vite 6

Fast dev server with HMR, configured in vite.config.js. Server rendering via @react-router.

Shopify App Bridge

Embedded admin UI, AppProvider from @shopify/shopify-app-react-router, and Polaris web components (s-page, s-button, …).

Shopify Admin GraphQL

Authenticated admin API through shopify.server.js; session storage handled by the app.

Prisma + SQLite

Database layer for sessions and app data, schema in prisma/schema.prisma.

Node.js 24 + pnpm

Runtime and package manager. Scripts defined in package.json (build, dev, lint, typecheck).

Shopify CLI

shopify app dev tunnels local development and installs the app on a development store.
